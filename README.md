# 🎓 Proyecto CrudAlumnos - ASP.NET Core MVC

Este proyecto es una aplicación web desarrollada con **ASP.NET Core MVC** y **Entity Framework Core** para la gestión de alumnos (Crear, Leer, Actualizar y Eliminar) asi mmismo poder tener un buen control.

---

## 🔗 Enlace Directo a la Aplicación

Para acceder al módulo principal de gestión de alumnos, iniciar el proyecto y abre la siguiente URL en tu navegador web:

👉 **[http://localhost:5102/Alumnos](http://localhost:5102/Alumnos)**

---

## 🛠️ Tecnologías Utilizadas

* **Framework:** .NET Core / ASP.NET Core MVC
* **ORM:** Entity Framework Core
* **Base de Datos:** SQL Server (LocalDB)
* **Frontend:** Razor Views, Bootstrap, HTML5, CSS3
